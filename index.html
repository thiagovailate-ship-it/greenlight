// como funciona

Da instalação ao merge em uma revisão

  1. 01

    Instale o app

    Um clique no GitHub Marketplace. Escolha os repositórios, defina as regras e pronto em dois minutos.

  2. 02

    Todo PR é revisado

    O Greenlight lê o diff em contexto — comentários inline, correções sugeridas e lacunas de teste sinalizadas na hora.

  3. 03

    Faça o merge quando estiver verde

    As checagens bloqueadas ficam verdes conforme os problemas são resolvidos. Nada de esperar revisor para o óbvio.

// recursos

Tudo o que um revisor sênior diria

  • Comentários inline na revisão

    O feedback aparece exatamente onde o código está — com contexto, severidade e correções em um clique.

  • Análise de segurança

    Cada diff é escaneado por injeção, segredos e padrões inseguros. Zero configuração.

  • Sugestões de teste

    Falta cobertura no branch novo? O Greenlight escreve o teste, você aprova.

  • Revisão em menos de 30s

    Tempo mediano de revisão em 1,2M de PRs — enquanto o CI ainda está aquecendo.

  • Aprende a sua base de código

    Regras da casa, padrões e convenções — revisados como o seu sênior faria.

  • Vive no seu terminal

    Um CLI e um app do GitHub no mesmo lugar. Rode gl review onde quiser.
